# Technical Architecture & Implementation Plan

## Tech Stack
*   **Frontend:** HTML5, Tailwind CSS, JavaScript (Vanilla ES6 or lightweight framework like Vue/React to allow seamless single-page-app hosting on GitHub Pages).
*   **Backend & Database:** Firebase Firestore (NoSQL cloud database).
*   **Authentication:** Firebase Auth (Email & Password setup).
*   **Hosting:** GitHub Pages (Client-side single page app routing).

## Database Schema (Firestore Collections)
1. **`users`**: `{ uid, email, role ("freelancer" | "hiring"), name, skillLevel, paymentDetails, createdAt }`
2. **`jobs`**: `{ jobId, hiringId, title, description, budget, milestonesCount, status ("open" | "interviewing" | "escrow_pending" | "active" | "completed" | "disputed"), proposalsCount, createdAt }`
3. **`proposals`**: `{ proposalId, jobId, freelancerId, bidAmount, coverLetter, status ("pending" | "accepted" | "rejected") }`
4. **`contracts`**: `{ contractId, jobId, hiringId, freelancerId, digitalSignatures: { hiring: text/date, freelancer: text/date }, milestones: [{ id, amount, status: "pending"|"escrowed"|"released" }], escrowStatus: "pending"|"secured"|"released"|"disputed", platformVerdict: null }`

## Core Workflows
1. **The Matchmaking Pipeline:** Job Post ➔ Freelancer Proposals ➔ Quick Interview/Chat ➔ Selection.
2. **The Escrow & Contract Pipeline:**
   *   Prior to start, a **Digital Contract** generated by the app must be signed by both parties.
   *   The Hiring Manager transfers the funds to the platform's manual gateway.
   *   The Admin flags the contract as `escrowed` in Firestore.
3. **Milestone Flexibility:** Supports a single lump-sum payout or up to 5 milestone structural splits.
4. **Dispute Resolution Protocol (Platform Absolute Authority):**
   *   If a Freelancer fails to complete or submit the work, the Admin reverts the job to "Open" allowing the Hiring Manager to rehire without additional platform costs.
   *   Once work is verified complete, payment is pushed.
   *   In cases of conflict, the Platform Administrator handles manual arbitration (verdict dictates half-pay, no-pay, or full-pay).

## Manual Escrow Supported Gateways
*   **Mobile Wallets:** KBZ Pay (KPay), Wave Money (WavePay), AYA Pay, CB Pay, UAB pay (sai sai pay).
*   **Traditional Banking:** Yoma Bank, AYA Bank, KBZ Bank, CB Bank.
*   **Digital Assets / Crypto:** USDT (TRC-20), Binance Pay, DJO Pay.
